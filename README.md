# CleanGEO — უსაფრთხო საძიებო სისტემა

საძიებო სისტემა, რომელიც **CleanGEO.txt** ბლოკ-ლისტს იყენებს: შედეგებში საშიში დომენები
მონიშნულია, ხოლო ბმულის გახსნისას საიტი იხსნება გაფილტრულ რეჟიმში — მისი სკრიპტები,
ტრეკერები და რეკლამები არ მუშაობს.

## რას აკეთებს

- **ძებნა** — DuckDuckGo + Bing + Wikipedia (API გასაღების გარეშე), შედეგები ერთ სიაში
- **ბლოკ-ლისტი** — `CleanGEO.txt` იტვირთება GitHub-იდან და ინახება მოწყობილობაზე
- **ავტომატური განახლება** — საიტი სისტემატურად ამოწმებს სიას (15 წთ / 1 სთ / 6 სთ / დღე),
  ასევე ტაბის გააქტიურებისას და ინტერნეტის დაბრუნებისას
- **წაშლილი წესები იშლება** — ახალი სია მთლიანად ცვლის ძველს, ცვლილებები (＋/−) ჩანს პარამეტრებში
- **დაცული კითხვის რეჟიმი** — გვერდი მოდის ტექსტური პროქსის გავლით და იწმინდება:
  `<script>`, `iframe`, `form`, `on*` ატრიბუტები, ტრეკერ-პიქსელები
- **cosmetic წესები** — სიის `##`, `#?#`, `#$#` წესები გამოიყენება როგორც CSS
- **საკუთარი წესები** — დამატებითი ხაზები, რომლებიც განახლებისას არ იშლება

## ფაილები

| ფაილი | დანიშნულება |
|---|---|
| `index.html` | **აწყობილი საიტი** — ყველაფერი ჩაშენებულია (CSS + JS), მუშაობს `file://`-იდანაც |
| `assets/style.css` | სტილები (mobile-first, ბნელი რეჟიმი, safe-area) |
| `assets/page.template.html` | გვერდის ჩარჩო, საიდანაც `index.html` იწყობა |
| `assets/blocklist.js` | AdGuard/ABP წესების ანალიზატორი და შემჩმევი |
| `assets/search.js` | საძიებო ძრავები |
| `assets/proxy.js` | დაცული კითხვის რეჟიმი (ჩატვირთვა, გაწმენდა, markdown) |
| `assets/store.js` | შენახვა, ავტომატური შემოწმება, დიფი |
| `assets/app.js` | UI |
| `CleanGEO.txt` | ბლოკ-ლისტი |

## აწყობა

წყაროებს ცვლით `assets/`-ში, შემდეგ:

```bash
python tools/build.py     # აწყობს index.html-ს
python tools/verify.py    # ამოწმებს ჩაშენებას, id-ებს, ფრჩხილებს
```

`tools/make_icons.py` აგენერირებს აპლიკაციის აიქონებს, `tools/test_engine.js` ამოწმებს
წესების ძრავას.
