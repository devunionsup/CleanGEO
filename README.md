# CleanGEO 🇬🇪

Полностью грузиноязычное iOS-приложение: блокировщик рекламы для Safari,
собственный рекурсивный DNS-резолвер с DNSSEC, DoH/DoT-шифрование,
обнаружение блокировок провайдера и опциональный VPN-туннель.

## Структура проекта

```
CleanGEO.xcodeproj/         Xcode-проект (3 таргета)
CleanGEO/                   основное приложение (SwiftUI)
  Sources → AppSupport/     фильтры, DNS, DNSSEC, туннель
  ka.lproj/                 грузинская локализация
BlockerExtension/           расширение Safari Content Blocker
Tests/                      юнит-тесты (XCTest)
tools/verify_logic.py       офлайн-проверка алгоритмов
.github/workflows/build.yml GitHub Actions: сборка IPA
```

## Что реализовано

1. **Блокировка рекламы в Safari** — Content Blocker extension читает
   скомпилированные правила из App Group; приложение компилирует
   AdGuard-совместимые фильтры (CleanGEO.txt + AdGuard Base + трекеры) в
   формат Safari (лимит 150 000 правил соблюдён).
2. **Автообновление 4 раза в сутки** — настраиваемое расписание (до 4
   времён), BGAppRefreshTask + проверка при запуске; при неудаче предыдущая
   рабочая версия фильтров сохраняется; показывается дата и число правил.
3. **Собственный рекурсивный DNS** — root servers → TLD → authoritative,
   кэш с TTL, случайные ID + 0x20 case randomization, bailiwick-проверки,
   ограничение числа переходов (анти-петля).
4. **DNSSEC** — построение цепочки доверия от IANA-корневых KSK
   (20326, 38696), проверка RRSIG (RSA-SHA256/512, ECDSA P-256/384,
   Ed25519), DS-дайджесты, проверка сроков подписи.
5. **Шифрование** — DoH (RFC 8484, POST application/dns-message) и DoT
   (RFC 7858, TLS 1.3). Без Google/Cloudflare/AdGuard DNS.
6. **Защита от блокировок провайдера** — детектор DNS-хиджекинга и
   IP-блокировок (TCP-проверки), NetworkExtension-туннель по требованию.
7. **Безопасность** — HTTPS-only загрузка фильтров, SHA-256 свёртки +
   опциональный подписанный manifest.json, без аналитики, без истории.

## Сборка IPA без Xcode на своём компьютере

1. Создайте пустой репозиторий на GitHub и загрузите туда содержимое
   проекта (или попросите меня — я подготовлю push через SSH).
2. Включите Actions — workflow `build.yml` собирает **unsigned IPA** и
   публикует его в артефактах (`CleanGEO-unsigned-ipa`).
3. Скачайте IPA и подпишите своим бесплатным сертификатом Apple через
   **Feather** или **SideStore** (пароль Apple ID вводится только в самом
   инструменте на устройстве — не в чате и не в GitHub).
4. Установите подписанный IPA, затем: Настройки → Safari → Расширения →
   CleanGEO → Разрешить.

## Что нужно от вас (и только это)

- **GitHub-репозиторий** (или пустой — я заполню) для Actions.
- Один раз — **подписать IPA** вашим сертификатом через Feather/SideStore.
- **Свой DNS-узел** (опционально): текущая конфигурация указывает на
  `dns.cleangeo.ge` и `tunnel.cleangeo.ge:51820`. Если у вас есть сервер
  (любой VPS), под ним разворачивается собственный резолвер — я подготовлю
  серверный код отдельно, скажите только адрес.
- **NetworkExtension entitlement** нужен только для VPN-туннеля: без него
  блокировка рекламы и DNS-защита работают; туннель подключается, когда
  профиль добавится через подпись с этой capability (Feather добавляет её
  при подписании).

## Отчёт о тестировании

Проверено офлайн (tools/verify_logic.py — алгоритмы, зеркалящие Swift-код):

| Проверка | Результат |
|---|---|
| Компилятор фильтров: блок, исключения, косметика, модификаторы, отбрасывание неподдерживаемых | ✅ 7/7 сценариев |
| Regex корректности блокировки (ложные срабатывания) | ✅ |
| RSA modpow (включая 2048-битный сценарий) | ✅ |
| DNS wire: кодирование, сжатие имён, защита от петель | ✅ |
| Логика расписания (4 слота, прошедшие/будущие, никогда не обновлялось) | ✅ |

XCTest-набор (`Tests/CleanGEOTests.swift`) прогоняется в CI на симуляторе
iPhone 15: компилятор, wire-формат, DNSSEC-канонизация, modpow, кэш,
расписание, сообщения об ошибках на грузинском.

**Честно не проверено на реальном устройстве** (нет iPhone в этой среде):
поведение Safari-расширения вживую, фоновое выполнение BGTask в реальном
времени, реальный DoH/DoT-трафик к вашему серверу, установка подписанного
IPA. Это стандартная граница: всё, что можно проверить без устройства,
проверено; остальное проверит CI и ваша первая установка.
